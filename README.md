# Bacteriocin gene tables

A stub from my BSc Honours in Biochemistry (Stellenbosch University, 2021). The project looked at bacteriocin gene hits, with immunity factors, in *Streptococcus mutans* genomes. This script is the start of a parser for those hit files. It opens one result file and does nothing more.

Kept for the record. It is not a working tool.
